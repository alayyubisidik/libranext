## Phase 4 v2 — Categories Filter, Sorting & Bulk Status

**Fitur penambahan filter status, sorting kategori, dan bulk change status pada halaman Categories Admin Dashboard.**

### Filter Status

* [ ] Tambahkan filter **Status** pada halaman Categories.
* [ ] Sediakan pilihan:

  * [ ] All Status
  * [ ] Active
  * [ ] Inactive
* [ ] Filter dapat digunakan bersamaan dengan search.

### Sorting

* [ ] Tambahkan fitur **Sort** pada halaman Categories.
* [ ] Sediakan pilihan:

  * [ ] Name A–Z
  * [ ] Name Z–A
  * [ ] Books Count Lowest → Highest
  * [ ] Books Count Highest → Lowest
  * [ ] Newest Added
  * [ ] Oldest Added
* [ ] Sorting dapat digunakan bersamaan dengan search dan filter status.

### Bulk Change Status

* [ ] Tambahkan checkbox pada setiap kategori untuk memilih kategori.
* [ ] Tambahkan checkbox untuk memilih semua kategori yang ditampilkan.
* [ ] Tampilkan **Bulk Status** ketika terdapat kategori yang dipilih.
* [ ] Sediakan pilihan status:

  * [ ] Active
  * [ ] Inactive
* [ ] Status menggunakan select/dropdown.
* [ ] Perubahan status dilakukan menggunakan **onchange submit**.
* [ ] Pastikan perubahan hanya diterapkan pada kategori yang dipilih.
* [ ] Setelah berhasil, tampilkan notification success.
* [ ] Setelah submit, pertahankan filter, sorting, dan search yang sedang digunakan.
